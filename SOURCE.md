# Data Source

## Dataset
NYC Taxi & Limousine Commission (TLC) — Yellow Taxi Trip Records

## URL
Trip Record Data Download Links: https://www.nyc.gov/site/tlc/about/tlc-trip-record-data.page

## What it is
Yellow taxi trip records include pickup and drop-off dates/times, pickup and drop-off
locations (as taxi zone IDs), trip distances, itemized fares, rate types, payment types,
and driver-reported passenger counts. Data is submitted to TLC directly by TLC-licensed
technology providers (TPEP vendors), not collected or generated by this project.

## Format
Published monthly, one PARQUET file per month, plus a static CSV taxi zone lookup table.
This project used a single month as its working dataset: `yellow_tripdata_2024-01.parquet`
(~47.6 MB, 2,964,624 rows), and `taxi_zone_lookup.csv` (265 zones).

## Update frequency
TLC publishes a new month's file on this page monthly, typically with roughly a two-month
lag from the trip date to allow vendors time to submit complete records. This project uses
a fixed, point-in-time snapshot (January 2024) rather than a live feed. The pipeline's
extract step is parameterized by year-month, so pointing it at a newly published month
requires changing only that parameter, not the pipeline logic.

## License / terms of use
Published by the City of New York under the city's general open terms of use:
http://www1.nyc.gov/home/terms-of-use.page. No account, API key, or payment is required.

## Accuracy disclaimer (from the publisher)
TLC states that the trip data was not created by TLC and that TLC makes no representations
as to its accuracy. This is directly relevant to this project's data-quality layer: the
silver-layer cleaning rules exist specifically to catch and remove the kinds of submission
errors (negative fares, impossible durations, invalid location codes) that this disclaimer
implicitly warns about.

## Why this dataset was chosen
- Large enough to be a realistic pipeline (millions of rows) while still runnable on
  free-tier compute when scoped to one month
- Naturally supports incremental/monthly loading, mapping directly to a real
  orchestration pattern (new file each month)
- Has genuine, well-documented data quality issues, giving the data-quality layer real
  work to do rather than being a formality
- Public, free, and requires no authentication, so an automated "extract" step can run
  unattended
